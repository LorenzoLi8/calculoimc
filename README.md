# Calculadora de IMC em Python

Projeto simples em Python para cálculo do Índice de Massa Corporal

## Funcionalidades

- Solicita a altura e peso do usuário
- Realiza o cálculo a partir de: float(peso/altura**2)
- O resultado é classificado a partir da tabela de referências
 - **Abaixo do peso**: Menor que 18.5
 - **Peso normal**: Entre 18.5 e 24.9
 - **Sobrepeso**: Entre 25 e 29.9
 - **Obesidade**: 30 ou mais

## Como executar
1. Certifique-se de ter Python 3 instalado
2. Baixe o arquivo calculoimc.py
3. Abra o terminal na pasta onde salvou o arquivo e execute:
```bash
   python calculadora_imc.py
   ```
